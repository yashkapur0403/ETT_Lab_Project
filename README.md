# ETT Lab Project

## AI-Driven BRSR/ESG Report Analyzer

### Project Description
Corporate sustainability and ESG (Environmental, Social, and Governance) reporting has become mandatory for many listed companies. These reports are usually published as long and unstructured documents, making manual extraction and analysis time-consuming and inefficient.

This project aims to develop a containerized AI-based document analysis system that can automatically process sustainability and business responsibility reports of publicly listed companies and generate structured, query-based insights. The system is designed for academic and research purposes, with a focus on transparency, portability, and document-grounded analysis.

---

## Project Objectives
- Automate the analysis of sustainability and business responsibility reports  
- Convert unstructured report content into structured, machine-readable outputs  
- Enable analytical queries and question answering over report content  
- Ensure responses are strictly grounded in source documents  
- Design a modular and portable system architecture  

---

## Problem Statement
Sustainability reports are typically long, unstructured, and difficult to analyze manually. Comparing ESG-related information across companies is challenging due to inconsistent formats and scattered data. This project addresses these challenges by introducing an AI-driven document intelligence workflow.

---

## Planned Workflow
1. Document ingestion  
2. Content extraction (text and tables)  
3. Segmentation and structuring  
4. Semantic indexing  
5. AI-based analysis  
6. Structured output generation
